# Matar el Rato - Client

Godot client for the Matar el Rato game.

## Prerequisites
- Godot 4.6 (C# Support)

## How to Run
1. Update source code:
   ```bash
   git pull
   ```
2. Open the project:
   - Launch Godot.
   - Import or open using the `project.godot` file.

Note: git is used for development/updates and is not required for players.
